# Изображения для реального запуска KartoFert

В текущей версии сайт не использует несуществующие локальные фото. Упаковки, картофель, земля и листья собраны CSS/SVG-компонентами, чтобы не было broken images.

Перед коммерческим запуском можно добавить реальные изображения:

- фото упаковок;
- фото гранул;
- фото картофеля;
- фото поля;
- фото склада;
- фото доставки;
- фото применения удобрений.

Рекомендации:

- хранить фотографии товаров в `public/images/products`;
- использовать единый формат карточек товара, например 1200×1200;
- не использовать фотографии без права публикации;
- для каждого товара добавить источник изображения и дату обновления.
