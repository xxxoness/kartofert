# Contributing

Thank you for your interest in this project.

KartoFert is currently maintained as a real small-business storefront and admin-dashboard project. Contributions, ideas, and technical improvements are welcome, especially around code quality, documentation, security, SEO, admin UX, and deployment workflow.

## Good contribution areas

- Bug fixes
- Documentation improvements
- Admin dashboard improvements
- Accessibility improvements
- SEO improvements
- Security hardening
- Tests and automated checks
- Refactoring without changing business behavior

## Before contributing

Please do not include real secrets, API keys, production credentials, admin hashes, database URLs, or private business data in commits.

Brand-specific assets such as the KartoFert name, logo, packaging, product photos, commercial texts, and legal texts may have separate usage restrictions. See `NOTICE.md`.
